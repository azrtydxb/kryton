## Command palette

Hit `⌘K` (or `Ctrl+K`) anywhere in Kryton. The palette opens at the top of the screen.

<AnnotatedImage
  src="/kryton/screenshots/command-palette.png"

It is the fastest way to:

- Jump to a note by name
- Run a command (new note, graph view, settings, …)
- Open something in split view (`⌘↵`)

All without leaving the keyboard.

## Tags

Any `#word` in a note becomes a tag. Tags are listed in the sidebar with their counts, and the Tags view (sidebar → **Tags**) shows the full alphabetised list.

---
title: Environment variables
description: Every environment variable the Kryton server reads, with type, default, and description.
---

The Kryton server's environment is validated by a Zod schema at boot. Anything below is read from `process.env`; anything unset falls back to the default (or fails fast for required vars).

Source of truth: [`packages/server/src/config/env.ts`](https://github.com/azrtydxb/kryton/blob/master/packages/server/src/config/env.ts). This page mirrors that schema verbatim; if it drifts, the schema wins.

## Runtime

| Variable | Type | Default | Description |
|---|---|---|---|
| `NODE_ENV` | `development` \| `test` \| `production` | `development` | Runtime environment. Set `production` in deploys — gates trust-proxy, secure cookies, and verbose logging. |
| `LOG_LEVEL` | `fatal` \| `error` \| `warn` \| `info` \| `debug` \| `trace` \| `silent` | `info` | Pino log level for the server. |
| `PORT` | number | `3001` | TCP port the HTTP server listens on. |
| `HOST` | string | `0.0.0.0` | Interface the HTTP server binds to. |

## Database

| Variable | Type | Default | Description |
|---|---|---|---|
| `POSTGRES_URL` | string (DSN) — **secret** | — | Postgres connection string for the Drizzle data layer. Optional at the schema level; the DB plugin enforces presence at registration time (so test harnesses can short-circuit). Format: `postgres://user:pass@host:port/db`. |

## Auth

| Variable | Type | Default | Description |
|---|---|---|---|
| `BETTER_AUTH_SECRET` | string ≥ 32 chars — **secret, required** | — | Signing secret for Better-Auth sessions. The server refuses to boot below 32 chars. Generate with `openssl rand -hex 32`. |
| `BETTER_AUTH_URL` | URL | `http://localhost:3001` | Public URL the server is reachable at for Better-Auth callbacks. |
| `APP_URL` | URL | `http://localhost:5173` | Public URL of the client app (used for OAuth redirects + CORS). |

## CORS and rate limiting

| Variable | Type | Default | Description |
|---|---|---|---|
| `CORS_ORIGINS` | comma-separated origins | `http://localhost:5173` | Allowed CORS origins. The schema splits on commas, trims, and filters empties. |
| `RATE_LIMIT_MAX` | number | `1000` | Max requests per rate-limit window per client. |
| `RATE_LIMIT_WINDOW` | duration string | `1 minute` | Rate-limit window (e.g. `"1 minute"`, `"15 minutes"`). |

## Storage

| Variable | Type | Default | Description |
|---|---|---|---|
| `NOTES_DIR` | path | `../../notes` | Filesystem path for note storage. In containers, set to a path under your persistent mount (e.g. `/data/notes`). |

## WebAuthn (passkeys)

| Variable | Type | Default | Description |
|---|---|---|---|
| `WEBAUTHN_RP_ID` | hostname | `localhost` | WebAuthn Relying Party ID. Must equal the hostname the user visits (no scheme, no port). Changing this after passkeys are registered invalidates them. |

## OAuth — Google

| Variable | Type | Default | Description |
|---|---|---|---|
| `GOOGLE_CLIENT_ID` | string (optional) | — | Google OAuth client ID. Public identifier. |
| `GOOGLE_CLIENT_SECRET` | string (optional) — **secret** | — | Google OAuth client secret. |

## OAuth — GitHub

| Variable | Type | Default | Description |
|---|---|---|---|
| `GITHUB_CLIENT_ID` | string (optional) | — | GitHub OAuth client ID. Public identifier. |
| `GITHUB_CLIENT_SECRET` | string (optional) — **secret** | — | GitHub OAuth client secret. |

## SMTP (transactional email)

| Variable | Type | Default | Description |
|---|---|---|---|
| `SMTP_HOST` | hostname (optional) | — | SMTP server hostname for outbound mail. |
| `SMTP_PORT` | number (optional) | — | SMTP server port (commonly 465 with `SMTP_SECURE=true`, or 587 with STARTTLS). |
| `SMTP_SECURE` | `"true"` \| `"false"` (optional) | — | Whether to use TLS for SMTP. |
| `SMTP_USER` | string (optional) | — | SMTP auth username. |
| `SMTP_PASS` | string (optional) — **secret** | — | SMTP auth password. |
| `SMTP_FROM` | RFC-5322 address (optional) | — | Default `From:` address for outbound mail. |

## OpenAPI

| Variable | Type | Default | Description |
|---|---|---|---|
| `OPENAPI_ENABLED` | `"true"` \| `"false"` | `"true"` | Enable the `/docs` OpenAPI UI. Disable in locked-down deployments. |

## Semantic search

| Variable | Type | Default | Description |
|---|---|---|---|
| `SEMANTIC_PROVIDER` | `pgvector-local` \| `novamem` \| `off` | `pgvector-local` | Embedder backend for semantic search. `off` disables the worker entirely (no model load, no polling) — useful for low-RAM hosts and tests. |
| `SEMANTIC_MODEL` | HuggingFace model id | `Xenova/all-MiniLM-L6-v2` | Local embedder model. Changing this requires re-embedding the corpus. |
| `SEMANTIC_DIMENSIONS` | number | `384` | Embedding vector dimensions. Must match the model. |
| `SEMANTIC_CHUNK_TOKENS` | number | `256` | Tokens per semantic-search chunk. |
| `SEMANTIC_CHUNK_OVERLAP` | number | `32` | Token overlap between adjacent chunks. |

## Audit decisions

The schema marks each variable with `secret` and `userFacing` flags consumed by the deployment-surface generators (Helm `values.yaml`, Operator CRD, config schema):

- Credentials / tokens / signing keys are `secret: true`.
- OAuth **client secrets** and SMTP credentials are `secret: true`.
- OAuth **client IDs** and SMTP host / port / from are `secret: false` — public identifiers.
- Operational knobs (`LOG_LEVEL`, `OPENAPI_ENABLED`, `NOTES_DIR`, `SEMANTIC_*` tuning) are `userFacing: false` — sensible defaults, not surfaced in Helm `values.yaml` top-level.
- User-tunable knobs (`NODE_ENV`, `PORT`, `HOST`, the `*_URL`s, CORS, rate limits, `WEBAUTHN_RP_ID`, OAuth IDs, the SMTP block) are `userFacing: true`.

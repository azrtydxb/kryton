This section is for operators self-hosting Kryton, integrators talking to the
server APIs, and developers building plugins. If you're just using Kryton, the
[Get Started](/kryton/start/) and [Use](/kryton/use/) sections cover everything
you need.

- **[Deployment](/kryton/advanced/deployment/docker-compose/)** — Docker Compose, Helm, the Kubernetes operator, backups, upgrades.
- **[Security](/kryton/advanced/security/auth-providers/)** — auth providers, API keys, MCP access, reverse proxy and TLS.
- **[API](/kryton/advanced/api/rest/)** — REST surface, MCP tools, Yjs WebSocket.
- **[Plugins](/kryton/advanced/plugins/overview/)** — building plugins for Kryton.
- **[Contributing](/kryton/advanced/contributing/dev-setup/)** — dev setup, commits, releases.
- **[Reference](/kryton/advanced/reference/env-vars/)** — env vars, configuration, CLI, changelog.

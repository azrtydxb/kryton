This is where the depth lives. Everything you need to run Kryton in production, extend it with plugins, or contribute back upstream.

Pick a section:

- **[Deployment](/kryton/advanced/deployment/docker-compose/)** — Docker Compose, the official Helm chart, the Kubernetes Operator, a free-tier self-host walkthrough, backups, and upgrades.
- **[Security](/kryton/advanced/security/auth-providers/)** — auth providers (email, OAuth, passkeys, 2FA), the API key model with MCP, and reverse-proxy / TLS recipes.
- **[API](/kryton/advanced/api/rest/)** — the REST surface (auto-generated from OpenAPI), the full MCP tool list, and the Yjs collaborative-editing WebSocket protocol.
- **[Plugins](/kryton/advanced/plugins/overview/)** — what a plugin is, a 30-line hello-world, every UI slot, code-fence renderers, and how to test and publish.
- **[Contributing](/kryton/advanced/contributing/dev-setup/)** — local dev setup, the Conventional Commits rules enforced by CI, and the release workflow.
- **[Reference](/kryton/advanced/reference/env-vars/)** — every environment variable, configuration schema, the CLI manual, and the changelog.

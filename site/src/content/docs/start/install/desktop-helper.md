A native one-click desktop installer for Kryton is on the roadmap, but it isn't ready yet.

For now, the supported way to run Kryton on your own machine is the Docker path. It's two commands and works the same on macOS, Linux, and Windows (via WSL).

Head back to [Install with Docker](/kryton/start/install/docker/) — that's the page you want.
